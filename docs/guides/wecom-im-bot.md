# 接入企业微信智能机器人（IM 双向对话）

Ongrid 通过企业微信**智能机器人的 API 模式（长连接）**接入企业微信：Manager 主动连接 `wss://openws.work.weixin.qq.com`，用机器人的 BotID 和长连接 Secret 完成订阅，之后群里 @机器人或单聊机器人的消息会交给 Ongrid 助手处理，回复以流式消息在同一条消息里逐步刷新。不需要公网回调地址，也不需要 Token / EncodingAESKey。

这与 **设置 → 通知** 里的「企业微信」渠道不同：通知渠道是群机器人 Webhook，只能单向推送告警；本文的机器人是双向多轮对话。

协议参考：[企业微信开发者中心 · 智能机器人长连接](https://developer.work.weixin.qq.com/document/path/101463)。

## 准备机器人

1. 在企业微信中创建智能机器人，进入机器人配置页，开启「API 模式」并选择「长连接」。
2. 记下 **BotID** 和 **Secret**。Secret 是长连接专用密钥，与「设置接收消息回调地址」模式的 Token / EncodingAESKey 无关。
3. 把机器人加入需要使用的群聊；单聊直接搜索机器人即可。

API 模式只能二选一。切换到「设置接收消息回调地址」会让长连接失效；Ongrid 只支持长连接方式。

## 在 Ongrid 中配置

进入 **设置 → IM → 添加 IM 平台 → 企业微信**：

| 字段 | 填写 |
| --- | --- |
| 名称 | 仅用于展示，例如「运维助手」 |
| 模式 | 固定为 stream（长连接） |
| app_id | 机器人的 BotID |
| app_secret | 长连接 Secret |
| allow_from | 可选。逗号分隔的企业微信 userid；留空表示企业内成员都能对话 |
| 回复语言 | 自动 / 中文 / English |

保存后，Stream Supervisor 会在约 30 秒内建立长连接，列表中的状态变为「运行中」。「测试」按钮在机器人已连接时直接确认长连接正常；未连接时会用保存的凭证订阅一次并立即断开。

Manager 只需要能出站访问 `openws.work.weixin.qq.com:443`，会遵守 `HTTPS_PROXY` / `NO_PROXY`。私有化部署的企业微信使用不同的长连接地址，当前版本暂不支持配置。

## 使用

- 群聊里 @机器人提问，或在单聊里直接发消息。开头的 @机器人 会被去掉后再交给助手。
- 支持文本、语音（企业微信转写后的文字）、图文混排中的文字。引用一条文本消息再 @机器人时，被引用的内容会一起交给助手。图片、文件、视频不处理。
- 同一个群（或同一个单聊）共用一个 Ongrid 会话。发送 `/new` 或「新会话」开始新会话。
- 助手的工具 `send_im_message` 可以通过机器人主动发消息：`im_app_id` 填 Ongrid 中的机器人 ID，`group_id` 填群的 chatid（单聊填 userid）。企业微信只会投递给已经有人和机器人对话过的会话。

## 限制

- **一个机器人同时只能保持一个长连接。** 新的订阅会把旧连接踢下线。不要让多个 Manager 副本、测试环境或其他工具共用同一个机器人，否则它们会互相踢下线，状态里会出现 `connection replaced`。
- 流式消息从第一帧起 10 分钟内必须结束。助手运行超过约 9.5 分钟时，最终回答会作为一条新的 Markdown 消息发出。
- 单条回复最多 20480 字节，超出部分会被截断并标注。
- 企业微信对每个会话的消息频率有限制（30 条/分钟、1000 条/小时）。
- 修改 allow_from 后，需要停用再启用该机器人（或重启 Manager）才会生效；只有修改凭证时 Supervisor 才会自动重连。
- 如果机器人的创建者不是企业超级管理员，回调里的 userid 是加密后的值。allow_from 需要填写这个值，可以在 Manager 日志 `wecom inbound from non-allowlisted sender` 中找到。

## 排障

| 现象 | 处理 |
| --- | --- |
| 状态「重连中」，错误含 `aibot_subscribe: errcode=…` | BotID 或 Secret 不对，或机器人没有开启 API 模式的长连接 |
| 错误含 `connection replaced` | 另一个客户端用同一个 BotID 订阅了，排查其他 Manager 或工具 |
| 错误含 `heartbeat` 或 `ws dial` | Manager 到企业微信的网络或代理不通 |
| 群里 @机器人没有回复 | 确认真正选中了机器人（不是手打同名文字），机器人在群里，发送者不被 allow_from 拦截 |
